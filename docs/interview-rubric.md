# Interview Practice Evaluation Rubric

This rubric describes a practice session only. It does not predict hiring outcomes.

| Category | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| Problem understanding | Not demonstrated | Partial | Mostly correct | Clear and complete |
| Approach | Not proposed | Incomplete | Reasonable | Well-structured |
| Algorithm selection | Not selected | Weak fit | Plausible fit | Clearly justified |
| Complexity | Not discussed | Partially correct | Mostly correct | Correct with trade-offs |
| Coding | Not attempted | Major gaps | Working direction | Clear implementation |
| Testing | Not attempted | Limited cases | Basic validation | Thoughtful coverage |
| Edge cases | Not considered | One case | Some relevant cases | Systematic coverage |
| Communication | Not demonstrated | Hard to follow | Understandable | Clear and concise |
| Follow-ups | Not attempted | Needs prompting | Answers basic questions | Handles trade-offs |

Only award a category value from recorded session evidence. Do not fabricate scores when the session is incomplete.
